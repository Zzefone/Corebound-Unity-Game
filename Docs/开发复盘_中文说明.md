# 开发复盘中文说明

英文提交版围绕一个实际开发问题：地面标识文字干扰暂停和通关弹窗的阅读。它不是全部开发工作的流水账。

## 问题

关卡地面上有区域、检查点和反应堆文字。检查 Windows 版本画面时，发现这些文字会出现在暂停或通关弹窗所在区域，与弹窗标题竞争。此外，重生时的提示可能在通关后残留。

## 排查与未完全成立的假设

自动测试中的暂停、通关和场景切换已经通过，说明弹窗的状态和功能正常，但这不能证明界面清楚。随后单独检查了实际运行画面。

最初地面文字使用 TextMesh，HUD 使用 Screen Space Canvas。第一次尝试把地面文字改为 World Space Canvas，以为更换文字的渲染方式就能解决问题。重新检查截图后，发现弹窗背景中仍能看到地面字样，所以这个修改不足以完成解决。

最终问题被收窄为：暂停和通关时，地面标识与临时游戏提示并不是当前需要的信息，应该由游戏状态统一控制显示。

## 解决

- GameHUD 在 Awake 中缓存地面使用的 World Space Canvas。
- 暂停或通关时关闭这些 Canvas；继续游戏时恢复。
- 暂停或通关时，HUD 不显示临时游戏消息。
- GameManager 在通关时清空旧消息，避免重生提示残留。
- 退出按钮保持在 HUD 层级的最后，确保始终可访问。

## 验证

重新生成相关场景、构建 Windows 版本并运行验证，最后记录的 28 项自动检查全部通过。同时检查最终暂停和通关截图，确认地面文字与旧重生提示不再干扰弹窗。

复盘如实说明：部分自动检查会移动小球到指定位置来单独测试触发器，因此不能声称已由真人完整试玩。你提交前应自己跑一遍游戏，检查键鼠操作、难度、音量和退出。
